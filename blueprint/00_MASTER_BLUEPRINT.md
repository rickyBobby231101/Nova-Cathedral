## Which files are authority, and which merely describe
Added 2026-09-03, because the difference was never stated and the confusion
cost months.

- **01_MYTHOS_CANON.md is authority.** The code answers to it. When a chat
  transcript and this file disagree about the mythos, this file is right —
  a merged, wrong version of the Silent Order and the Harmonic Accord was
  once written into the knowledge graph from a transcript while the correct
  version sat here. Only Chazel writes it.
- **02, 03 are descriptive.** They record what Nova *is*. When they and the
  code disagree, the code is right and the document is stale.
- **04 is intent.** What comes next, and why, in order.

The failure this distinction prevents: 02 named Observer, Oracle and Echo, and
for months only Oracle existed — while every system prompt Nova generated
asserted all three. A descriptive file was read as if it were a description of
reality rather than of intent, so nobody went looking for the missing two.
